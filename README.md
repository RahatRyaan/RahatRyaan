## 🔧 Engineering Highlights

- **Auth:** JWT access tokens with rotating refresh tokens and token-family reuse detection that revokes the whole session on replay (Nexus, SyncBoard).
- **Concurrency:** optimistic concurrency control with typed `409 VERSION_CONFLICT` responses, and fractional indexing for concurrent drag-and-drop ordering.
- **Real-time:** Socket.io with Redis pub/sub fan-out for multi-instance scaling. SyncBoard was load-tested with 200 concurrent WebSocket clients.
- **AI / RAG:** pgvector (HNSW) with BullMQ workers for chunking, semantic search and summarization.
- **Testing:** Jest + Supertest integration tests and Playwright E2E across projects. SkillMap AI has 173 unit/API tests and 20 E2E tests covering NoSQL injection, token tampering and cross-account access.
- **Payments:** Stripe and SSLCommerz with webhook deduplication and idempotency controls.
